# タイトル
バーンアウト回復仮説に基づくLP・導線・KPIの再設計

## 本文

### 背景
初回検証を踏まえ、仮説を「学習習慣が失われている人に刺さる」から「バーンアウト後の回復を必要とする人に刺さる」へ更新する。

### 新仮説
思考を手放せず消耗したPM / リーダー層は、小さな記録習慣によって自己肯定感を回復し、少しずつ日常に戻ることができる。

### 対応内容

- [ ] 初回体験とページ遷移設計を回復導線に合わせて見直す
- [ ] `dailygoal` / `journal` / `ifthen` / `深呼吸して忘れる` の位置づけを再整理
- [ ] 継続率、再訪率、記入率、主観改善を計測指標として追加する

### 完了条件
- [ ] 継続率、再訪率、記入率、主観改善の改善が確認できている
